### 1. 🔬 [Industrial Surface Defect Inspection via Simplex Diffusion](https://github.com/hakammra/diffusion_texture_inspection)
> **Self-Supervised Anomaly Segmentation & Dual-Pathway Crease Disambiguation**

<table>
  <tr>
    <td width="65%" valign="top">
      <p>An end-to-end unsupervised surface inspection framework adapting <b>Dynamic Transformer UNet (DTU-Net)</b> with 4D Simplex noise diffusion backbones for industrial defect localization. Extended with a novel <b>Sliding-Window Tiled Dual-Pathway Engine</b> with cosine boundary compensation for full-field textile inspection ($1024 \times 1024$ and larger).</p>
      <ul>
        <li><b>MVTec Leather Benchmark</b>: Achieved <b>0.994 Image AUROC</b> and <b>0.998 Average Precision</b> with 7.0 px clean false alarm area.</li>
        <li><b>Industrial Fabric Stain Benchmark</b>: <b>0.810 AUROC / 0.977 AP</b> across 466 samples, accurately disambiguating chemical stains from structural fold creases.</li>
        <li><b>Production Features</b>: Full web visual diagnostic gallery, locked benchmark splits, automated validation pipeline.</li>
      </ul>
      <p>
        <code>PyTorch</code> <code>Diffusion Models (DDPM)</code> <code>DTU-Net</code> <code>CUDA</code> <code>OpenCV</code> <code>Scikit-Learn</code>

### 2. ⚡ [High-Speed Region-Aware Machine Vision Engine](https://github.com/hakammra/printed_label_inspection)
> **Deterministic Sub-Pixel Packaging Inspection Solving the Generative AI Paradox**

<table>
  <tr>
    <td width="65%" valign="top">
      <p>A production-grade Automated Optical Inspection (AOI) engine engineered for high-throughput pharmaceutical and manufacturing packaging labels. Investigates the <i>Generative Reconstruction Paradox</i> (where generative diffusion models miss missing barcodes/text by trivially reconstructing smooth white paper) and solves it using a deterministic multi-stream spatial architecture.</p>
      <ul>
        <li><b>Perfect Defect Recall</b>: <b>100.0% sensitivity</b> (43/43 defects) and <b>100% specificity</b> (10/10 normal controls) across 53 physical test captures.</li>
        <li><b>High-Throughput Line Rate</b>: Runs at <b>~80 ms per label on standard CPU</b> (vs. 3,780 ms on GPU for generative diffusion).</li>
        <li><b>Sub-Pixel Alignment</b>: Four-corner fiducial homography warp to a canonical $1063 \times 650$ coordinate frame with dynamic photometric normalization.</li>
      </ul>
      <p>
        <code>Python</code> <code>Machine Vision</code> <code>Homography Matrix</code> <code>OpenCV</code> <code>NumPy</code> <code>SciPy</code> <code>Embedded CPU</code>
      </p>
    </td>
    <td width="35%" valign="middle" align="center">

### 4. 🤟 [Real-Time ASL Fingerspelling Recognizer](https://github.com/hakammra/asl-fingerspelling-webcam)
> **Edge-Capable Hand Gesture Recognition with Calibrated SVM & Temporal Voting**

<table>
  <tr>
    <td width="65%" valign="top">
      <p>A lightweight webcam system that extracts normalized 3D hand landmark coordinates via MediaPipe, classifies American Sign Language (ASL) alphabet poses using a calibrated Support Vector Machine (SVM), and eliminates jitter via confidence thresholds, rejection poses, and temporal voting filters.</p>
      <ul>
        <li><b>Real-Time Performance</b>: Runs at full webcam FPS on standard CPU without dedicated GPU acceleration.</li>
        <li><b>Temporal Smoothing</b>: 5-frame temporal majority voting filter suppressing transitional classification noise.</li>
      </ul>
      <p><code>Python</code> <code>MediaPipe</code> <code>OpenCV</code> <code>Scikit-Learn</code> <code>NumPy</code></p>
